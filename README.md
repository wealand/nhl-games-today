# NHL Games Tracker

A lightweight, mobile-friendly web application for tracking daily NHL hockey games, live scores, TV broadcast channels, betting odds, and full team season schedules.

## Features
- **Daily Scoreboard:** Displays today's games by default with live scores, start times, and period status.
- **Browse by Date:** Seamlessly browse past and future game dates using the date picker or previous/next navigation buttons.
- **Filter by Team:** Filter daily matchups by any of the 32 NHL teams or view an entire franchise's upcoming season schedule.
- **Broadcast & Betting Odds:** Shows network broadcasts (ESPN, TNT, Sportsnet, regional sports networks) and betting favorite lines.
- **Mobile Responsive:** Clean, dark-mode design optimized for mobile phones and desktops.
- **Zero Configuration:** Powered directly by ESPN's public CORS-friendly APIs without requiring API keys or backend servers.

## Local Development
Open `index.html` directly in any modern browser:

```bash
# Using python simple server
python3 -m http.server 8080

# Open in browser
open http://localhost:8080
```
